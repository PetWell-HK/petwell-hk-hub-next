# 50 篇寵物護理博客 — 封面圖生成指南

逐篇製作封面時，請將圖片存為 **`article-XX-hero.jpg`**，放入此資料夾 `public/blog-pet-care-hk/`。

---

## 全篇通用規格

| 項目 | 要求 |
|------|------|
| **檔名** | `article-01-hero.jpg` … `article-50-hero.jpg` |
| **尺寸** | **1200 × 675 px**（16:9 橫向） |
| **格式** | JPG 或 WebP，建議每張 **< 200 KB** |
| **用途** | 文章頂部大圖 + 主人專區列表卡片縮圖 |
| **風格** | 明亮、清晰、專業寵物博客風；自然光；香港家居／診所／戶外情境均可 |
| **構圖** | 主體置中或三分法；**預留上下邊緣空間**（列表裁切時可能切到邊） |
| **色調** | 與 PetWell 品牌協調：暖白、淺橙點綴可；避免過暗或過飽和 |

### 請避免

- 可辨識的**品牌商標、包裝文字、藥品標籤特寫**（易有版權／合規問題）→ 用「類似產品」或無標籤道具代替
- 血腥、受傷、驚嚇畫面
- 可辨識真人樣貌（除非你有授權）
- 圖上疊加文章標題文字（標題由網頁顯示即可）

### AI 生成工具建議

以下每篇附有 **English Prompt**，可直接貼到 Midjourney、DALL·E、Gemini、Adobe Firefly 等。生成後裁切至 16:9，再壓縮上傳。

**通用後綴（可加在每條 Prompt 末尾）：**
```
, professional pet blog hero image, bright natural lighting, shallow depth of field, 16:9 composition, high quality photograph, no text, no logos, no watermarks
```
